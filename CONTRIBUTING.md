# Contributing · Cómo contribuir

*English below · Español más abajo*

## English

Thank you for reading the book. If you find a mistake, please tell us. It helps every reader who comes after you.

**How to report a mistake**

Open an issue: <https://github.com/ElviraGD-lab/field-to-code-statistics/issues/new>

Please include:

1. **The page:** the link to the lesson, and the language (Spanish or English).
2. **What is wrong:** quote the sentence, the number or the line of code.
3. **What it should be,** if you know.
4. **For code that does not run:** the exact command, the full error message, your operating system, and the versions of Python and of the library that failed (`python --version` and `conda list pandas`, for example).

**Corrections go through issues, not pull requests.** Both language versions of the book are kept in step from one source text. If we change the source, the Spanish and the English pages stay the same. A pull request to one page would make them drift apart. The same applies to the scripts in `code/`: they are tested together with the lessons.

Questions about the content and ideas for the book are welcome as issues too.

By contributing, you agree that your contribution is published under the licences of the book: CC BY 4.0 for the text and Apache 2.0 for the code.

## Español

Gracias por leer el libro. Si encuentras un error, cuéntanoslo: ayuda a todos los que lo lean después.

**Cómo avisar de un error**

Abre una incidencia (*issue*): <https://github.com/ElviraGD-lab/field-to-code-statistics/issues/new>

Indica, por favor:

1. **La página:** el enlace a la lección y el idioma (español o inglés).
2. **Qué está mal:** copia la frase, el número o la línea de código.
3. **Cómo debería ser,** si lo sabes.
4. **Si el código no funciona:** el comando exacto, el mensaje de error completo, tu sistema operativo y las versiones de Python y de la librería que falló (por ejemplo, `python --version` y `conda list pandas`).

**Las correcciones se hacen con incidencias, no con *pull requests*.** Las dos versiones del libro salen de un mismo texto de origen. Si corregimos el origen, las páginas en español y en inglés siguen siendo iguales; un *pull request* a una sola página haría que se separaran. Lo mismo vale para los scripts de `code/`: se prueban junto con las lecciones.

También son bienvenidas como incidencias las preguntas sobre el contenido y las ideas para el libro.

Al contribuir, aceptas que tu aportación se publique con las licencias del libro: CC BY 4.0 para el texto y Apache 2.0 para el código.
