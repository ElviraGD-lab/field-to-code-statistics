# Code

One script per chapter: `chNN_slug.py`. Each script contains every code block of its chapter, in the same order, and runs from top to bottom without errors.

Run from the repository folder, with the environment active:

```bash
python code/ch01_first_look.py
```

In VS Code the scripts can also be run cell by cell: every `# %%` line starts a cell.

Paths to the data are set at the top of each script. See `data/README.md` for where each file comes from and how to get it again.
